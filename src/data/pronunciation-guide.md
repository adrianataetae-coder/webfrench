# French Pronunciation Guide (Spanish Phonetics)

## Vocalizes
- **a** = /a/ (como "casa")
- **e** = /ə/ (como "e" suave, muda al final)
- **é** = /e/ (como "é" de "mesa")
- **è** = /ɛ/ (como "é" de "pensé")
- **ê** = /ɛ/ (como "è")
- **i** = /i/ (como "i" de "sip")
- **o** = /ɔ/ (como "o" de "cosa")
- **ô** = /o/ (como "ó" de "todo")
- **u** = /y/ (como "ü" alemana, NO como "u" española)
- **ou** = /u/ (como "u" de "uno")
- **eu** = /ø/ (como "ö" alemana)
- **eux** = /ø/ (como "ö" alemana)

## Consonantes
- **b** = /b/ (como "b" de "bajo")
- **c** = /k/ antes de a,o,u /s/ antes de e,i
- **ç** = /s/ (como "c" de "casa")
- **d** = /d/ (como "d" de "dato")
- **f** = /f/ (como "f" de "foto")
- **g** = /g/ antes de a,o,u /ʒ/ antes de e,i
- **h** = mudo (NUNCA se pronuncia)
- **j** = /ʒ/ (como "j" de "jamón" pero más suave)
- **k** = /k/ (como "k" de "kilo")
- **l** = /l/ (como "l" de "luna")
- **m** = /m/ (como "m" de "madre")
- **n** = /n/ (como "n" de "nana")
- **p** = /p/ (como "p" de "papo")
- **q** = /k/ (como "k")
- **r** = /ʁ/ (gutural, como "j" española pero más atrás)
- **s** = /s/ entre vocales /z/
- **t** = /t/ (como "t" de "taco")
- **v** = /v/ (como "v" inglesa)
- **w** = /w/ (como "gü" de "güeco")
- **x** = /ks/ o /gz/
- **y** = /i/ (como "i")
- **z** = /z/ (como "z" inglesa)

## Combinaciones
- **ch** = /ʃ/ (como "sh" de "shop")
- **gn** = /ɲ/ (como "ñ" de "año")
- **gu** = /g/ antes de e,i
- **qu** = /k/
- **th** = /t/ (la "h" es muda)
- **ph** = /f/

## Nasales (la "n" o "m" NO se pronuncia, la vocal es nasal)
- **an/en** = /ɑ̃/ (como "an" nasal)
- **on** = /ɔ̃/ (como "on" nasal)
- **in/ain/ein** = /ɛ̃/ (como "an" nasal)
- **un** = /œ̃/ (como "un" nasal)

## Ligaduras
- **oi** = /wa/ (como "gua" de "guapo")
- **ai/ei** = /ɛ/ (como "é")
- **au/eau** = /o/ (como "ó")
- **ou** = /u/ (como "u")
- **eu** = /ø/ (como "ö")
- **ie** = /jə/ o /je/

## Terminaciones
- **-er** = /e/ (infinitivo, como "é")
- **-ez** = /e/ (como "é")
- **-es** = /ə/ (mudo al final)
- **-ent** = /ə/ (mudo en verbos)
- **-tion** = /sjɔ̃/ (como "sión")
- **-sion** = /zjɔ̃/ (como "sión")
- **-ment** = /mɑ̃/ (adverbios, como "man")
- **-e** (final) = mudo
- **-eux/-eu** = /ø/ (como "ö")
- **-ille** = /ij/ (como "í")
- **-ien** = /jɛ̃/ (como "ien" nasal)
- **-on** = /ɔ̃/ (como "on" nasal)

## Contracciones Comunes
- **J'** + vocal = /ʒ/ = "Zh" (pero suena como "sh" antes de ciertas consonantes)
- **Je** = /ʒə/ = "Zhë"
- **Tu** = /ty/ = "tü" (NO "tu")
- **Il** = /il/ = "il"
- **Elle** = /ɛl/ = "el"
- **Nous** = /nu/ = "nu"
- **Vous** = /vu/ = "vu"
- **Ils** = /il/ = "il" (la "s" es muda)
- **Elles** = /ɛl/ = "el" (la "s" es muda)

## Pronombres Contractados
- **J'suis** = /ʒsɥi/ = "shuí"
- **J'vais** = /ʒve/ = "shvé"
- **J'me** = /ʒmə/ = "shme"
- **J'ne** = /ʒnə/ = "shne"
- **T'ne** = /tnə/ = "tne"
- **J'prendrai** = /ʒpʁɑ̃dʁe/ = "shprandre"

## Palabras Comunes
- le/la/l' = /lə/ /la/ /l/ = "le/la/l'" (artículos)
- les = /le/ = "le" (plural, "s" muda)
- un/une = /œ̃/ /œn/ = "ün/ün"
- des = /de/ = "de"
- et = /e/ = "é"
- ou = /u/ = "u"
- mais = /mɛ/ = "mé"
- donc = /dɔ̃/ = "don"
- avec = /avɛk/ = "avèk"
- pour = /puʁ/ = "pur"
- par = /paʁ/ = "par"
- dans = /dɑ̃/ = "dan"
- sur = /syʁ/ = "súr"
- sous = /su/ = "su"
- devant = /dəvɑ̃/ = "devan"
- après = /apʁɛ/ = "apri"
- avant = /avɑ̃/ = "avan"
- ici = /isi/ = "isí"
- où = /u/ = "u"
- quand = /kɑ̃/ = "kan"
- comment = /kɔmɑ̃/ = "komán"
- pourquoi = /puʁkwa/ = "purkuá"
- est-ce que = /ɛskə/ = "eskë"

## Números
- un = /œ̃/ = "ün"
- deux = /dø/ = "dö"
- trois = /tʁwa/ = "truá"
- quatre = /katʁ/ = "kátr"
- cinq = /sɛ̃k/ = "sank"
- six = /sis/ = "sis"
- sept = /sɛt/ = "sèt"
- huit = /ɥit/ = "üit"
- neuf = /nœf/ = "nöf"
- dix = /dis/ = "dis"

## Errores Comunes
- NO confundir "u" (/y/) con "ou" (/u/)
- "e" final casi siempre es muda
- "h" siempre es muda
- "s" al final de palabra es muda
- "ent" en verbos es mudo
- Las nasales NO tienen la "n" o "m" pronunciada
